Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda saat menggunakan aplikasi BlueSignal AI.

2. Informasi yang Kami Kumpulkan
Untuk menyediakan layanan pemantauan zona penangkapan ikan dan analisis data maritim secara real-time, aplikasi kami mengumpulkan beberapa jenis informasi berikut:

Data Lokasi (GPS & Jaringan): Mengakses lokasi perangkat saat aplikasi digunakan untuk menampilkan posisi kapal pada peta maritim dan menyesuaikan prediksi zona potensi penangkapan ikan secara akurat.
Data Perangkat & Log: Informasi teknis seperti model perangkat, versi sistem operasi (Android), ID unik perangkat, dan statistik performa untuk optimasi aplikasi.
3. Penggunaan Informasi
Informasi yang dikumpulkan digunakan semata-mata untuk memprediksi titik potensi penangkapan ikan, memandu navigasi lokal pada peta interaktif, memproses autentikasi pengguna, serta menjaga keamanan infrastruktur backend (Firebase).
